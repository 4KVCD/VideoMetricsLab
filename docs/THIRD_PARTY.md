## The macOS bundle

`scripts/build_release_macos.sh` builds `VideoMetricsLab.app` (Apple silicon)
with the same app code and these components in place of the Windows ones; the
others above (nlohmann/json, miniz, the VMAF v1 models, Qt's translations)
are the same. Licence files ship in `Contents/Resources/licenses/` and beside
each tool, as on Windows. FFmpeg and ffprobe themselves are not bundled
(Homebrew's, found on the PATH or in its folders).

The macOS bundle has no MinGW, MSVC or NVIDIA component; its `libvmaf` and
`vship` licence folders are Windows' (they include the winpthreads,
pthreads4w and nv-codec-headers notices, which apply only to the Windows
builds).

Qt's LGPL distribution requirements need attention: its libraries ship as
Qt built them, as separate DLLs beside the programs.

The Vship command-line executable and FFMS2 DLL are intentionally not bundled;
the app feeds frames to Vship's library API (Vship 5.1's C API) instead, decoded by
FFmpeg or by the GPU's own decoder through the frame decoders above, from the
compressed stream FFmpeg copies out of the container. The Vulkan build needs only the GPU driver's `vulkan-1.dll`. When it
cannot use a GPU -- no driver, or initialization fails -- GPU scoring is off
for that run: SSIMULACRA2 and Butteraugli use the bundled libjxl
CPU tools, and CVVDP, which has no CPU implementation, is not calculated.
