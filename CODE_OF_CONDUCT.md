# Community guidelines

Be welcoming, respectful and constructive. Critique ideas and code, not
people. Assume good intent, accept corrections, and respect privacy.

Harassment, threats, discriminatory abuse, sexual harassment and publishing
someone's private information are not acceptable in project spaces.

Maintainers may edit or remove abusive content, lock discussions, or restrict
participation. Decisions should be proportionate and consider context.

For sensitive conduct reports, contact a maintainer through a private contact
method they list on their GitHub profile. Do not post private details in a
public issue. If no private method is available, use GitHub's reporting tools
for platform abuse. This project does not yet operate a dedicated conduct inbox.
