The model files require an external FFmpeg/libvmaf build new enough to
implement the VMAF v1 feature set. Older builds should use VMAF v0 models.
The HDR-VMAF models also need a libvmaf built with zimg, which converts the
pictures to the colour space they declare; the app scores them in its own
process with the bundled libvmaf.
